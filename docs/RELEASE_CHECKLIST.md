# 发布检查清单

## 已具备的工程基线

- [x] 唯一后端源码入口、安全默认配置及无生产地址的示例
- [x] 安全回归测试、构建命令、CI 工作流
- [x] 贡献/安全/隐私/部署/迁移文档与 MIT 许可文本
- [x] 白名单源码导出与基础敏感信息检查

## 正式开源发布前需由维护者完成

- [ ] 确认代码与资源权属，并确认采用 MIT；补充第三方完整许可审查和 SBOM
- [ ] 设置仓库负责人、安全私密报告渠道、仓库描述与版本规则
- [ ] 扫描全部 Git 历史和导出包，轮换曾暴露的部署凭据
- [ ] 对原版本依赖运行漏洞扫描，升级受影响组件并回归验证
- [ ] 在 MySQL 8.4 上运行空库初始化、业务集成测试、数据库副本迁移与备份恢复
- [ ] 验证 Docker/Nginx/HTTPS/限流配置及非 root 运行
- [ ] 在标准 SDK 环境构建两个 Android 应用，真机验证、单独配置正式签名
- [ ] 验证全部业务写接口和浏览器流程，完成安全评审及数据保留策略
- [ ] 在全新目录解压发布包并重新构建，再创建 release/tag

不要把“源码可供审阅”描述为“通过生产安全审计”。
