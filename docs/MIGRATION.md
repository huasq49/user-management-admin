# 从旧私有版本迁移

本轮没有连接或部署生产服务器，也没有修改真实数据库。旧外层后端、脚本、发布产物及地理库保留在 `.local/pre-open-source/`，该目录严禁公开。

1. 备份数据库和旧发行包，在隔离测试实例验证；根目录 `backend` 现以较新快照为基准。
2. 提供强随机环境变量；旧默认密码现在会导致启动失败。轮换任何曾共享凭据。
3. 对现有库保持 `DDL_AUTO=validate`，遇到差异先编写审核过的迁移 SQL，不要在生产直接自动 update。
4. 旧 `/api/overview`、`/api/dashboard` 增加管理员鉴权；用户无效会话返回 401，改密后需重新登录。
5. 头衔授予返回最小角色 DTO，密码哈希/头像字节不再序列化。
6. WebSocket 停用；客户端改用 `GET /api/client/chat/messages?after=<id>` 并带用户 Bearer 令牌轮询。
7. 地理归属地统一“未知”，不是 IP 记录已停止采集。未来扩展须核验授权及隐私。
8. Android HTTPS 强制；applicationId 变更需作为新应用安装，旧签名不能直接沿用。
9. 旧签名 v1 算法不变，但 nonce 限为 16–128 位字母/数字/下划线/横线，时间窗 ±300 秒。禁止多副本共享此内存实现。
10. 文档中旧测试结果不再作为新版本保证，以 VALIDATION.md 的本次实测为准。

头像现在只接受PNG/JPEG，最大200KB、边长4096；历史HTML/SVG等伪图片不能继续访问。Android请求增加超时并禁止自动重定向，服务地址须直接指向最终HTTPS源站。
