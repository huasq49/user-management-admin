# 隐私与数据处理参考

这不是适用于所有地区的法律文本，部署者必须制定自己的隐私告知及保留策略。

系统可能保存：账号标识和密码哈希、头像、登录会话、设备代码/名称、IP、访问和心跳时间、卡密记录、预设文件、聊天内容及审核/封禁状态。开源版默认不进行 IP 地理库查询，也不向外部地理服务发送 IP。

部署前应明确处理目的、合法依据、知情授权、管理员访问范围、保存期限、导出/删除与申诉渠道。只收集业务所需数据；不得用于未告知的跟踪监控。

目前没有完整的数据生命周期自动清理或用户自助删除实现，部署方须设计审核过的清理流程并验证外键关系与备份保留期限。不要直接执行未经验证的批量删除 SQL。
